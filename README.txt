HOW TO USE THE HTML ARTICLE
The HTML article uses relative image paths. Keep the HTML file, logo, and five images in the same folder, or upload the complete ZIP while preserving every filename.

The page is self-contained and does not load external fonts, scripts, or stylesheets. It includes responsive styling, social metadata, Article schema, print styling, captions, alt text, and a link to the printable owner planner.

Before publishing, replace the placeholder community section or link with the live Lux Automaton community URL.

HOW TO USE THE MARKDOWN FILE
The Markdown file includes YAML front matter for title, subtitle, slug, author, date, excerpt, SEO description, category, tags, and featured image. Relative image filenames match the assets in this folder.

HOW TO USE THE OWNER PLANNER
Open private-ai-business-os-owner-planner.html in a browser. Use the Print / Save as PDF button to print it on US Letter paper or save a PDF copy. The planner helps an owner:
1. Inventory scattered apps and files
2. Identify business context to unify
3. Select one guided workflow
4. Define privacy, permissions, and approvals
5. Plan a 30-day pilot
6. Measure operational improvement
